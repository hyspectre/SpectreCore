# SpectreCore — Hydev

Plugin modular RPG para Paper 1.21.10 (Java 21).

> **Estado del repositorio:** inicialización. La fuente completa de `0.7.3-m3-alpha` todavía está pendiente de incorporarse. **No instalar en producción** hasta compilar y validar en un servidor de pruebas.

## Filosofía

**Optimización · Rendimiento · Limpieza de código · Seguridad**

El contenido de juego y la presentación deben ser configurables mediante YAML. La documentación para jugadores utiliza `/mago` con Dialogs y GUI complementarias; la administración técnica conserva `/spectrecore`.

## Ecosistema de Hydev

MythicLib/MMOItems, MythicMobs, ItemsAdder, AuraSkills, FancyNPCs, FancyHolograms, zMenu, WorldGuard, LuckPerms, Essentials, FastAsyncWorldEdit y otras integraciones opcionales cuando corresponda.

## Próximos pasos de publicación

Incorporar el árbol completo del paquete `SpectreCore_GitHub_INICIAL_0.7.3-m3` (fuentes, recursos YAML, pruebas y workflow), ejecutar GitHub Actions y corregir los errores que detecte la compilación.

No incluir mundos, datos de jugadores, plugins propietarios, credenciales ni backups del servidor.
